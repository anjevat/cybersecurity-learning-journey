# HTTP vs HTTPS

## Overview

HTTP (Hypertext Transfer Protocol) is used for communication between web clients and servers.

HTTPS is the secure version of HTTP. It uses TLS to encrypt communication between the client and server.

## HTTP

- Sends data without encryption.
- Uses port 80 by default.
- Data can potentially be intercepted or modified.

## HTTPS

- Encrypts communication using TLS.
- Uses port 443 by default.
- Helps protect confidentiality and data integrity.
- Helps authenticate the server through digital certificates.

## Security Relevance

HTTPS is important for protecting sensitive information such as login credentials, payment details, and session data while it travels across a network.

## Key Difference

HTTP provides web communication, while HTTPS adds **encryption, integrity, and server authentication** through TLS.
