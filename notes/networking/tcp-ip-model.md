# TCP/IP Model

## Overview

The TCP/IP model is a networking framework used to describe how data is transmitted across networks and the Internet.

## Layers

1. Application Layer
   - Provides network services directly to applications.
   - Examples: HTTP, DNS, FTP, SSH.

2. Transport Layer
   - Provides end-to-end communication between devices.
   - Main protocols: TCP and UDP.

3. Internet Layer
   - Handles logical addressing and routing of packets.
   - Main protocol: IP.

4. Network Access Layer
   - Handles communication over the physical/local network.
   - Examples: Ethernet and Wi-Fi.

## Key Point

Data moves down the layers when being transmitted and up the layers when being received.
