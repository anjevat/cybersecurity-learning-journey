# Ports and Network Services

## Overview

A network port is a logical endpoint used by applications and services to communicate over a network.

Ports are identified by numbers from **0 to 65535**.

## Common Ports

| Port | Protocol/Service | Purpose |
|---|---|---|
| 20/21 | FTP | File transfer |
| 22 | SSH | Secure remote access |
| 23 | Telnet | Remote access |
| 25 | SMTP | Email transmission |
| 53 | DNS | Domain name resolution |
| 80 | HTTP | Web traffic |
| 443 | HTTPS | Secure web traffic |
| 3389 | RDP | Remote desktop |

## Security Relevance

Knowing common ports helps security professionals:

- Identify running network services.
- Understand how devices communicate.
- Investigate suspicious connections.
- Perform authorized network assessments.

## Key Point

An IP address identifies a device on a network, while a port identifies a specific service or application endpoint on that device.
