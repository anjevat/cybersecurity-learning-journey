# OSI Model

## Overview

The OSI (Open Systems Interconnection) model is a 7-layer framework used to understand how data moves between devices over a network.

## The 7 Layers

1. **Physical** — Transmits raw bits through cables, radio, or other physical media.
2. **Data Link** — Handles frames, MAC addresses, and local network communication.
3. **Network** — Handles logical addressing and routing using IP addresses.
4. **Transport** — Provides end-to-end communication using protocols such as TCP and UDP.
5. **Session** — Establishes, manages, and terminates communication sessions.
6. **Presentation** — Handles data formatting, encryption, and compression.
7. **Application** — Provides network services directly to applications, such as HTTP, DNS, and FTP.

## Key Point

Data moves down the layers when being transmitted and up the layers when being received.
