# DHCP (Dynamic Host Configuration Protocol)

## Overview

DHCP is a network protocol that automatically provides devices with network configuration information.

## Information Provided by DHCP

- IP address
- Subnet mask
- Default gateway
- DNS server

## Basic DHCP Process

The process is commonly remembered as **DORA**:

1. **Discover** — Client searches for a DHCP server.
2. **Offer** — Server offers an IP configuration.
3. **Request** — Client requests the offered configuration.
4. **Acknowledge** — Server confirms the assignment.

## Benefits

- Reduces manual IP configuration.
- Prevents many IP address conflicts.
- Makes network administration easier.

## Security Relevance

Attackers can abuse DHCP through techniques such as rogue DHCP servers, which can provide victims with malicious network settings.

## Key Point

DHCP automatically configures network devices, making IP address management easier and more efficient.
