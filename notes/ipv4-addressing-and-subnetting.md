# IPv4 Addressing and Subnetting

## Overview

IPv4 is a logical addressing system used to identify devices on an IP network. An IPv4 address consists of 32 bits and is written as four octets.

Example:

192.168.1.10

## IPv4 Address Structure

An IPv4 address has two main parts:

- Network portion — identifies the network.
- Host portion — identifies a device on the network.

## Subnet Mask

A subnet mask determines which part of an IPv4 address represents the network and which part represents the host.

Example:

IP Address: 192.168.1.10
Subnet Mask: 255.255.255.0
CIDR: /24

## Subnetting

Subnetting is the process of dividing one network into smaller networks called subnets.

### Benefits

- Better IP address management
- Reduced broadcast traffic
- Improved network organization
- Can improve network security through segmentation

## Key Point

Understanding IPv4 addressing and subnetting is essential for network configuration, troubleshooting, and cybersecurity.
