# TCP vs UDP

## Overview

TCP and UDP are Transport Layer protocols used for communication between devices over a network.

## TCP

TCP (Transmission Control Protocol) is connection-oriented and provides reliable data delivery.

### Features
- Connection-oriented
- Reliable delivery
- Error checking and retransmission
- Maintains packet order
- Uses a three-way handshake

### Common Uses
- HTTP/HTTPS
- SSH
- FTP
- Email

## UDP

UDP (User Datagram Protocol) is connectionless and focuses on speed rather than guaranteed delivery.

### Features
- Connectionless
- Faster and lightweight
- No guaranteed delivery
- No packet ordering
- Lower overhead

### Common Uses
- DNS
- DHCP
- VoIP
- Online gaming
- Streaming

## Key Difference

TCP prioritizes **reliability**, while UDP prioritizes **speed and lower overhead**.
